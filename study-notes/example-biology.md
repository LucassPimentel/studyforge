# Notas de Biologia — Célula (exemplo)

Estas são notas de estudo de exemplo. O MCP filesystem server dá ao Kiro acesso de leitura
a esta pasta, para que o agente possa ler notas como estas e ajudar a montar linhas no
formato `pergunta :: resposta` que o StudyForge usa para gerar cards.

- A mitocôndria é a organela responsável pela produção de energia (ATP) na célula.
- O núcleo armazena o material genético (DNA) da célula.
- A membrana plasmática controla a entrada e saída de substâncias na célula.
- Os ribossomos são responsáveis pela síntese de proteínas.
- A parede celular está presente em células vegetais, mas não em células animais.
